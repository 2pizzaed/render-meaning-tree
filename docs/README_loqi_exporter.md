# Loqi Exporter

Модуль для экспорта объектов Python в loqi-формат для последующей обработки алгоритмами проверки.

## Архитектура

Экспортер состоит из следующих основных компонентов:

### 1. LoqiExporter
Главный класс-координатор экспорта. Управляет процессом экспорта всех объектов, отслеживает уникальность имён и записывает результат в файл.

### 2. ObjectExporter
Абстрактный базовый класс для экспортеров конкретных типов объектов. Определяет интерфейс для:
- Получения имени объекта
- Получения имени класса
- Экспорта свойств
- Экспорта отношений

### 3. ValueConverter
Конвертер скалярных значений из Python в loqi-формат:
- `None` → отсутствие свойства
- `bool` → `true`/`false`
- `str` → строка (с экранированием при необходимости)
- `Enum` → `EnumClass:enum_value`

### 4. NameRegistry
Реестр имён объектов для обеспечения уникальности. Генерирует уникальные имена на основе существующих id или создаёт новые при необходимости.

## Поддерживаемые типы объектов

### Уровень абстракций (abstractions.py)
- `Effects` - эффекты действий
- `Behaviour` - поведение действий
- `Constraints` - ограничения переходов
- `ActionSpec` - спецификация действий
- `TransitionSpec` - спецификация переходов
- `ConstructSpec` - спецификация конструкций

### Уровень CFG (cfg.py)
- `Metadata` - метаданные узлов и рёбер
- `Node` - узлы графа потока управления
- `Edge` - рёбра графа потока управления
- `CFG` - граф потока управления

## Примеры использования

### Базовый экспорт объектов

```python
from src.cfg.loqi_exporter import LoqiExporter
from src.cfg.abstractions import Effects, InterruptionType

# Создание экспортера
exporter = LoqiExporter()

# Создание объекта
effect = Effects(interruption_stop=InterruptionType.BREAK)

# Добавление объекта для экспорта
exporter.add_object(effect)

# Экспорт в файл
exporter.write_to_file("output.loqi")
```

### Экспорт CFG

```python
from src.cfg.loqi_exporter import LoqiExporter
from src.cfg.cfg import CFG

# Создание CFG
cfg = CFG("my_cfg")

# Экспорт всего CFG и связанных объектов
exporter = LoqiExporter()
exporter.export_cfg(cfg, "cfg_output.loqi")
```

## Формат вывода

Экспортер генерирует loqi-код в следующем формате:

```loqi
obj <name> : <ClassName> {
    <property> = <value>;
    <relationship>(<object_name>);
}
```

### Пример вывода

```loqi
obj effect_1 : Effect {
    interruption_stop = InterruptionType:break;
}

obj node_cfg_100 : Node {
    id = "cfg_100";
    role = "BEGIN";
    kind = "begin";
    hasEffects(effect_1);
}
```

## Особенности реализации

1. **Двухпроходный экспорт**: Сначала регистрируются все объекты и их имена, затем выполняется экспорт свойств и отношений.

2. **Уникальность имён**: Все имена объектов проверяются на уникальность. При коллизии добавляется числовой суффикс.

3. **Использование существующих id**: Для объектов с полем `id` (Node, Edge, CFG) используется существующий id как база для имени.

4. **Обработка None**: Свойства со значением `None` не экспортируются.

5. **Обработка списков**: Списки объектов (например, Effects) экспортируются как отдельные объекты с отношениями.

6. **Полная перезапись**: Файл полностью перезаписывается при каждом экспорте.
